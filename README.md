**Gerenciador de Notas (JS Vanilla)**

Projeto simples pra treinar manipulação de DOM e lógica de validação. A ideia é gerenciar notas de alunos de um jeito simples e visual.

**O que ele faz?**
  - Calcula a média na hora (passou quem tirou 7 ou +).
  - O botão só clica se você preencher todos os campos (validação em tempo real).
  - Dá pra apagar o card do aluno se você cadastrar errado.
  - Layout limpo e direto.

**O que usei?**
  - **HTML5**
  - **CSS3**
  - **JavaScript**

**O que aprendi/reforcei**
  - Como usar o `insertAdjacentHTML` pra performance ser melhor que o `innerHTML`.
  - Manipular eventos de `input` pra deixar a interface "viva".
  - Template Literals pra deixar o código do HTML no JS muito mais bonito.
